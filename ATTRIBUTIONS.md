## Audio Sources

Recommended free sources for royalty-free Viking/Norse music:

- [Freesound.org](https://freesound.org) — filter by CC0 or CC BY
- [Free Music Archive](https://freemusicarchive.org) — filter by license
- [Musopen](https://musopen.org) — public domain classical recordings
- Original compositions (commissioned or self-created)

## Note to Contributors

When adding new bundled songs, you MUST:
1. Verify the audio file's license permits redistribution
2. Add an entry to this ATTRIBUTIONS.md file with source URL and license
3. Include the license text if required by the license terms
